# Legacy Upstream Guidance

This file is retained from the upstream `career-ops` project for reference only.

## Important

This fork is no longer being treated as a Claude-only repository.
Primary direction is:
- Codex for batch/agent execution
- OpenClaw for orchestration and browser-assisted flows
- file-based reports, tracker updates, and PDF generation preserved from upstream

## Use this file as historical context, not source of truth

The live operating guidance for this fork is now in:
- `AGENTS.md`
- `modes/_shared.md`
- `config/profile.example.yml`
- `templates/states.yml`

## What is still useful from upstream

Upstream contributed several good ideas that remain worth preserving:
- file-first job-search workflow
- report generation and tracker discipline
- PDF tailoring pipeline
- portal scanning concept
- explicit integrity checks for tracker state

## What should not be treated as canonical anymore

Do not assume this fork is:
- Claude Code-first
- Spanish-first
- tuned to Santiago’s exact AI-role search
- using `claude -p` workers as the default path

Those assumptions are being removed as the fork is adapted.
